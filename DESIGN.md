# Design System

## Colors (WCAG AA 4.5:1 compliant)

| Role | Value | Usage |
|---|---|---|
| Dark | #1E1E1E | Backgrounds, headings, dark sections |
| Blue (light BG) | #0B6FCC | Links, buttons, accents on white/light surfaces |
| Blue (dark BG) | #1E90FF | Links, buttons, accents on dark surfaces |
| Light BG | #F5F5F7 | Page backgrounds, card surfaces |
| White | #FFFFFF | Cards, text on dark |
| Muted | #5A6370 | Secondary text, captions |
| Blue Hover | #1576D6 | Interactive hover states |
| Blue Tint | #E8F4FF | Subtle highlights, light tints |

## Typography

- **Family:** Plus Jakarta Sans (Google Fonts)
- **Weights:** 400 (body), 500 (medium), 600 (semibold), 700 (bold), 800 (extrabold for hero)

## Spacing

- Base unit: 8px
- Section padding: 80px–120px vertical
- Card gaps: 24px–32px

## Elevation

- Cards: subtle shadow, no heavy drop shadows
- Hover: slight lift with transition
