Features

Change Case

Uppercase, Lowercase, Capitalized, Title Case, camelCase, PascalCase, snake_case, kebab-case, aLtErNaTiNg, and INVERSE. Results appear as you type.

Find & Replace

Powerful find and replace with case matching. Add prefixes and suffixes to every line. Strip HTML tags. URL and HTML encode/decode.

Clean & Sort

Remove duplicate lines, strip empty lines, and trim whitespace in one tap. Sort alphabetically or numerically, ascending or descending.

Analyze Text

Instant character, word, sentence, and paragraph counts with estimated reading time. Find duplicate lines. Extract emails, URLs, or numbers.

Generate

Create Lorem Ipsum placeholder text. Generate strong, customizable passwords with a real-time strength indicator.

Encode & Format

Encode and decode Base64. Prettify or minify JSON and XML. Add line numbers in multiple formats. Generate clean URL slugs.

Reverse & Merge

Reverse text by characters or lines. Merge lines into paragraphs. Manipulate text structure exactly how you need it.

Dark Mode

Dark mode, light mode, or match your system automatically. Copy results with one tap. Clean, intuitive interface.

Perfect For

Developers formatting code

Convert variable names between camelCase, snake_case, and kebab-case. Prettify JSON payloads. Encode URLs and Base64 strings.

Writers polishing content

Convert headings to Title Case, count words for deadlines, remove duplicate paragraphs, and clean up pasted text from other sources.

Students organizing notes

Sort study lists alphabetically, remove duplicates, count words for essays, and clean up notes copied from websites.
